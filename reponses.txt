Git indique "Déjà à jour" donc pas de merge explicite
Pour forcer un commit de merge :
git switch -c feature1-alt <hash du commit>a2d97d1
echo "Ajout temporaire dans feature1-alt" >> README.md
git add README.md
git commit -m "Ajout temporaire pour forcer le merge"
git switch develop
git merge feature1-alt

------------------------------------------------------------
11. Explication de merge :
------------------------------------------------------------
La commande `git merge <branche>` permet de fusionner l’historique de deux branches et 
elle crée un commit de fusion si les branches ont divergé, et conserve l’ordre des commits.

------------------------------------------------------------
12. Explication de rebase :
------------------------------------------------------------
La commande `git rebase <branche> ca réécrit l’historique de la branche courante
pour y mettre les commits de la branche cible linéairement elle est utile
pour un historiqueclair sans commits de merge multiples

Dans ce TP, le rebase a été utilisé pour :
fusionner plusieurs commits (squash)
insérer proprement le travail de feature4 dans develop
